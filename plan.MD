# Codewars Leaderboard — Rubric Checklist

- [ ] Website contains an input to accept a comma-separated list of users.
- [ ] Submitting the list fetches data from the Codewars API for each user.
- [ ] A dropdown is shown with all possible language rankings plus the overall ranking.
- [ ] The default ranking selected is the overall ranking.
- [ ] A table is shown for the currently selected ranking.
- [ ] The table contains columns for username, clan, and score.
- [ ] Changing the selected ranking updates the table.
- [ ] The table is sorted from highest to lowest score.
- [ ] Users without a ranking for the selected language are not shown.
- [ ] The top user's score is visually highlighted.
- [ ] Website scores 100% for accessibility in Lighthouse Desktop Snapshot mode for all views.
- [ ] Unit tests are written for at least one non-trivial function.
- [ ] Project contains no dead code.
- [ ] Searching for a user who doesn't exist shows a useful message.
- [ ] If multiple users are searched for, each invalid user is identified or an appropriate error is shown.
- [ ] API/network errors show a useful error message.
- [ ] Error messages do not make misleading claims.
- [ ] Error messages clearly explain what the user should do to resolve the problem.
- [ ] GitHub repository contains the completed project.
- [ ] Website is deployed and publicly accessible.
- [ ] Website automatically deploys when changes are merged to GitHub.
